# File formats

## Recommendations

Strong recommendation for Zarr 3.0 zipstore. Easy to write one file or many into a single .zip package, can include arbitrary datatypes / large file sizes (performant) plus metadata. 

Secondary recommendation for HDF5 - widely adopted
